# LaveroAdmin

### Modern administration tools for Laravel.

LaveroAdmin is an independent open-source project focused on extending and improving the Laravel administration experience.

Built upon the foundation of [Open Admin](https://github.com/open-admin-org/open-admin), LaveroAdmin brings compatibility with modern Laravel versions, additional improvements, and a growing ecosystem of extensions.

Our goal is to provide developers with a flexible and practical toolkit for building, managing, and maintaining Laravel applications.

## Our ecosystem

- **Core** — administration panel and development foundation.
- **Extensions** — additional functionality for everyday development and application management.
- **Integrations** — tools that connect different services and simplify workflows.

## Projects

- [LaveroAdmin Core](https://github.com/LaveroAdmin/LaveroAdmin) — the main administration panel.
- [All repositories](https://github.com/orgs/LaveroAdmin/repositories) — explore our extensions and tools.

## Our principles

- Open source and transparency.
- Compatibility with modern Laravel versions.
- Extensibility and modularity.
- Practical tools for developers.
- Continuous improvement.
